# ProyectoIntegrador UI

Frontend React + TypeScript + Vite para ProyectoIntegrador.

Scripts:

```bash
npm install
npm run dev
npm run build
```

Variables de entorno:

```env
VITE_API_BASE_URL=https://your-backend-domain.example
VITE_SUPABASE_URL=https://your-project-ref.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

Deploy:

- El proyecto ya está preparado para desplegarse desde la raíz de este repositorio.
- El output de producción es `dist`.
